# Проверка версии 1.3.14

27 октября 2026. В этой версии поменялись два оттенка. Расположение элементов и звук не менялись.

Код audio host, worker, settings и bridge побайтно совпал с 1.3.13. В CSS и popup.js после обратной подстановки цветов и нормализации окончаний строк других изменений не осталось.

Быстрые тесты прошли **8/8**. Браузерный сценарий повторён в Chrome 156.0.8078.48 и Яндексе 26.10.0.1854: прошли оба. Проверялись настоящий tabCapture, спектр, drag/Q, пресеты, две вкладки, Stop/Start, остановка worker и перезапуск браузера.

Сравнение с исходным bg.js на 3 конфигурациях и 256 частотах дало максимальное наблюдаемое расхождение АЧХ 0 дБ.

Подробные результаты: [Chrome](test-evidence/github-chrome-results.json), [Яндекс](test-evidence/github-yandex-results.json). Новые снимки: [Chrome](test-evidence/github-chrome-controls.png), [Яндекс](test-evidence/github-yandex-controls.png).

Отдельный фоновый прогон 1.3.14 длился 5 секунд. Для 1.3.13 есть прогон на 60 секунд — это разные результаты. Часами работу, все DRM-сервисы и смену физического аудиоустройства не проверяли.
