# Что убрано и какие доступы остались

Проверка от 27 октября 2026. Просмотрены manifest, JS, HTML/CSS/SVG и локальная Snap.svg. Старый фоновый код для сравнения фильтров запускался только в отдельном тестовом документе, с удалённым в памяти загрузчиком аналитики.

## Из оригинала убрано

- Google Analytics `UA-64913318-2`, события действий и загрузка `ga.js` из сети.
- Синхронизация пресетов через `chrome.storage.sync`.
- Неиспользуемый AJAX-транспорт Snap.svg. Snap.load теперь тоже не может сходить в сеть и завершится локальной ошибкой.
- Загрузка favicon вкладки по внешнему адресу: вместо неё используется локальная иконка.
- Рекламные и неработающие Pro/purchase-ссылки, старые key, update_url и _metadata.

Импорт пресетов проверяет JSON и числа до сохранения. NaN, Infinity, неподходящие структуры и ключи `__proto__`, `constructor`, `prototype` не принимаются.

## Зачем нужны разрешения

`activeTab` — выбранная пользователем вкладка, `tabCapture` — её звук, `offscreen` — место для Web Audio после закрытия popup, `storage` — локальные настройки. Других разрешений нет. Нет host permissions, content scripts и разрешения tabs или истории.

`tabs.query({})` нужен для значков EQ на вкладках. Без дополнительных разрешений он не открывает произвольные URL и историю. URL активной вкладки проверяется при подключении, чтобы отказывать на служебных страницах.

ID и заголовок подключённой вкладки живут в памяти offscreen для Active Tabs. На диск они не пишутся. Сохраняются фильтры, gain и пресеты. Названия пресетов попадут в JSON, если пользователь сам нажмёт экспорт.

## Сеть и сообщения

CSP запрещает соединения через `connect-src 'none'`, удалённые скрипты, eval и object. Inline-стили оставлены для SVG/Snap и исходной компоновки; inline-скрипты не разрешены. Ссылки в Guide открываются только по клику.

Worker принимает команды панели только от своего popup, offscreen — от своего worker. Внешних обработчиков сообщений и web-accessible resources нет. Между частями расширения передаются параметры и спектральные значения, а не аудиозаписи.

В наблюдаемых контекстах расширения при браузерных тестах было **0 JS exceptions и 0 внешних HTTP-запросов**. Это не учёт всего трафика браузера или музыкального сайта. Результаты лежат в [test-evidence](test-evidence).

## Зависимости

В самом расширении осталась Snap.svg 0.4.1 с Eve 0.4.2 и mina. Она локальная, с удалённым сетевым транспортом. Произвольные SVG или HTML в неё не импортируются. Этот просмотр не доказывает отсутствие всех возможных уязвимостей старой библиотеки; добавление такого импорта потребует отдельной проверки.

Playwright нужен только для тестов и в установочный ZIP не попадает. Сборка использует стандартную библиотеку Python и ничего не скачивает.
