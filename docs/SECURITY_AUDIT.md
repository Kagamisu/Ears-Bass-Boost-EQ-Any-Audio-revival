## Текущие границы

Только `activeTab`, `tabCapture`, `offscreen`, `storage`. Разрешения tabs и host permissions отсутствуют. Content scripts не внедряются, DOM сайтов не читается. `tabs.query({})` используется для очистки badge; без tabs/host permissions это не открывает историю или произвольные URL. URL активной вкладки проверяется только для отказа на служебных страницах.

У живого stream в памяти offscreen находятся ID и заголовок вкладки для Active Tabs. Они не сохраняются на диск и удаляются с записью stream. Настройки хранят только фильтры/gain/пресеты. Названия пользовательских пресетов — данные пользователя и могут попасть в экспортируемый им JSON.

CSP блокирует сетевые соединения (`connect-src 'none'`), удалённый JS и object. Inline **скрипты** и eval не разрешены. Inline **стили** оставлены для оригинального SVG/Snap и позиционирования, это не разрешение исполнять inline JS. Все runtime scripts лежат в extension. Ссылки Guide ведут на внешние инструкции только после явного клика пользователя; их открытие — обычная навигация браузера.

Worker принимает команды UI только от собственного popup; offscreen — только от собственного worker. Externally connectable API, web-accessible resources и внешние message handlers отсутствуют. Аудио не записывается на диск, не отправляется в сеть и не попадает в JSON сообщений. В FFT передаются только численные спектральные значения внутри расширения.

## Зависимости

В runtime только исходный Snap.svg 0.4.1, включая Eve 0.4.2 и mina. Не добавлялись npm runtime-зависимости и UI-фреймворки. Библиотека оставлена локально, её AJAX-транспорт удалён с отметкой изменения. Загрузка SVG по URL нигде не используется. Это аудит наблюдаемых механизмов, а не гарантия отсутствия любых уязвимостей старой библиотеки. Добавлять импорт произвольных SVG/HTML без отдельного аудита нельзя.

Playwright закреплён в devDependencies и нужен только для тестов, не входит в устанавливаемый ZIP. Сборка использует стандартную библиотеку Python и не скачивает код.

Реальные браузерные проверки: JS exceptions расширения — 0, внешних HTTP-запросов из наблюдаемых контекстов расширения — 0. Сетевой трафик самого Яндекс Браузера/Chrome к его штатным сервисам не является трафиком расширения и этим проектом не отключается. Доказательства в `test-evidence/*-results.json`.
