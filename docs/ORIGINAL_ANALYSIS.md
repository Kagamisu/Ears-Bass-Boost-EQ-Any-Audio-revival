# Анализ оригинальной Ears 1.3.12

Основной источник — пользовательский `1.3.12_0.rar`, а не описание расширения в магазине. SHA-256: `b5e537b9d3537aa2ad401cd6c6f4316048aab717eb7c11bcbbff24bf dabb46cb` (пробел разделяет длинную строку для чтения; точное значение — в original-inventory.json). Файлы оригинала при распаковке и анализе не изменялись.

## Фоновый код

Минифицированный `bg.js`, автор в manifest — Kevin King. Постоянная фоновая HTML-страница создаёт один `AudioContext({latencyHint:'playback'})`, input gain 1, 11 BiquadFilter и output GainNode. Захваченные вкладки подключаются к одному input. Внутренняя таблица хранит stream, tab и audioSource для каждой вкладки. Число вкладок не определяет число цепочек EQ: цепочка одна.

Исходные частоты: 20, 40, 80, 160, 320, 640, 1280, 2560, 5120, 10240, 20480 Гц. Первый фильтр lowshelf, последний highshelf, остальные peaking. Для всех Q = 0.7071, gain = 0. При живом редактировании, сбросе и применении пресета частота ограничивается 5–20000 Гц; начальное значение верхней полки 20480 Гц — особенность оригинала, сохранённая в Revival. Gain фильтра −30…+30 дБ, Q 0.2…11. Общий gain 0.00316…10, исходно 1.

Нейтральные фильтры оригинал динамически исключал из цепи. Фильтры с ненулевым gain шли по возрастанию индекса, затем output gain и destination. Для UI общий gain переводился через `10*log10`, обратное преобразование `10^(value/10)`; эта необычная шкала сохранена. Компрессора, лимитера, реверберации и изменения скорости в архиве нет.

Есть один встроенный пресет `bassBoost`: фильтры сбрасываются, low shelf переносится на 340 Гц с +5 дБ. Пользовательские пресеты содержат массивы `frequencies`, `gains`, `qs` по 11 элементов. Общий gain в пресет не входит. Пресеты хранились в localStorage `PRESETS` и `chrome.storage.sync` под `PRESETS.<имя>`. Параметры фильтров — `filter0`…`filter10` (`f`, `g`, `q`), общий gain — `GAIN`.

Анализатор подключался после output gain: FFT 8192, smoothingTimeConstant 0.5. Popup опрашивал его примерно 30 раз в секунду. После прекращения опроса analyser отключался. Оригинальный код при каждой отрисовке создавал новый SVG-градиент; удаление полилинии не удаляло градиент из defs.

При открытии popup оригинал автоматически добавлял текущую вкладку. Повторное добавление останавливало уже существующий stream; обработка этого случая в Revival сделана идемпотентной. Удаление вкладки и всех tracks обрабатывались неполно. В архиве также есть проверка изменения sample rate новым временным AudioContext и специальный обработчик fullscreen; браузерные ограничения fullscreen не являются отдельной аудиофункцией.

## Интерфейс

`popup.js` рисует график через Snap.svg 0.4.1 и содержит всю логику drag, Shift-drag, double click и пресетов. График EQ 600×300, общий gain 30×300, минимальная ширина body 640 px, минимальная высота html 500 px. Частотная шкала использует корень четвёртой степени, не обычную логарифмическую ось. Палитра: #2C3E50, wheat, #9573A8, #CDF7E1. CSS-компоновка и эта шкала сохранены; в GitHub edition 1.3.14 отдельно изменены два близких оттенка.

`popup.html` содержит Controls, Guide, Active Tabs; кнопки EQ, пресеты и ссылки. Присутствует недействующая Pro-логика, ограничивающая функции только если локальная переменная не null; в этой версии она null. Лимита в 3 пресета фактически нет. Названия пресетов и подсказки не переводились, чтобы сохранить привычный интерфейс.

## Что несовместимо с MV3

| Оригинал | Причина | Замена |
| --- | --- | --- |
| `background.scripts`, постоянная background page | Worker не имеет document/window и может быть остановлен | Service worker + offscreen |
| AudioContext и MediaStream в background page | В worker нет оконного Web Audio/DOM API | Web Audio в offscreen |
| `chrome.tabCapture.capture()` | Foreground-only API не предназначен для worker | Worker получает stream ID, offscreen получает media stream |
| localStorage в фоне | В service worker localStorage отсутствует | chrome.storage.local |
| Передача состояния через живые объекты фона | Worker непостоянен, MediaStream нельзя передать JSON-сообщением | Явные команды и сериализуемые snapshots |
| `browser_action`, `tabs.getSelected` | Старые имена/устаревший API | action, tabs.query |
| GA script через удалённый URL и разрешающий его CSP | Удалённый исполняемый код несовместим с MV3 и требованиями проекта | Полное удаление аналитики, CSP self |

Требования и схема подтверждены [документацией tabCapture](https://developer.chrome.com/docs/extensions/reference/api/tabCapture), [offscreen](https://developer.chrome.com/docs/extensions/reference/api/offscreen) и [миграцией worker](https://developer.chrome.com/docs/extensions/develop/migrate/to-service-workers). Сам tabCapture не отменён: изменён способ его использования.
