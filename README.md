# Ears 1.3.12 Revival

[![Project checks](https://github.com/Kagamisu/ears-revival/actions/workflows/checks.yml/badge.svg)](https://github.com/Kagamisu/ears-revival/actions/workflows/checks.yml)

Неофициальное восстановление классического браузерного эквалайзера Ears 1.3.12 для **Manifest V3**. Версия GitHub edition: **1.3.14**.

Сохранены привычная компоновка, 11 точек эквалайзера, регулятор громкости, Spectrum Visualizer, вкладки Controls / Guide / Active Tabs и работа с пресетами. Палитра слегка изменена: фон `#293B4B`, основной цвет `#F0D6A5`. Размер графика остаётся 600×300, как у оригинала.

## Установка в Яндекс Браузер

1. Нажмите **Code → Download ZIP** и распакуйте проект в постоянную папку.
2. Откройте `browser://extensions`.
3. Включите **Режим разработчика** → **Загрузить распакованное расширение**.
4. Выберите подпапку **`extension`**, где непосредственно находится `manifest.json`.
5. Закрепите значок Ears. Откройте страницу со звуком и нажмите значок расширения: эта вкладка подключится к эквалайзеру.

В Chrome используйте `chrome://extensions`. Нужны API Chromium 116+: `tabCapture`, `offscreen` и `runtime.getContexts`. Node.js и Python для установки не нужны.

Папку установленного расширения нельзя удалять или перемещать. При обновлении замените её файлы и нажмите **Обновить/Перезагрузить** на карточке расширения. Во время перезагрузки расширения его аудиозахват прервётся; затем подключите вкладки снова. Пресеты перед обновлением можно сохранить через Export Presets.

Яндекс может отдельно отключать локальные расширения при запуске — при необходимости включите его снова. Сборка не является публикацией в Chrome Web Store и не обновляет старое расширение автоматически.

## Управление

- Перетаскивание точки — частота и усиление. **Shift + перетаскивание** вверх/вниз — ширина фильтра Q.
- Двойной щелчок — сброс одного фильтра. **Reset Filters** — сброс всех фильтров и общего gain.
- Линия **volume** слева — общий gain. Сохранена исходная шкала Ears.
- **Bass Boost** — исходная низкая полка на 340 Гц, +5 дБ.
- **Spectrum Visualizer** — спектр после обработки.
- **Save / Delete / Import / Export Presets** — пользовательские настройки в исходном JSON-формате Ears. Пресеты сохраняют фильтры, не общий gain.
- **Stop EQing This Tab** — отключение обработки текущей вкладки без перезагрузки страницы.
- **Active Tabs** — отдельное отключение подключённых вкладок. Чтобы добавить другую вкладку, откройте на ней Ears.
- **Open in Full Window** — тот же интерфейс в отдельной вкладке. График сохраняет исходный фиксированный размер и не растягивается на весь монитор.

Как в оригинале, все подключённые вкладки используют **общий EQ и gain**. Независимыми остаются их подключение и отключение. Закрытие popup не останавливает обработку. После перезапуска браузера настройки остаются, но вкладки подключаются заново действием пользователя.

## Звук и приватность

Звук обрабатывается локально через Web Audio в offscreen-документе. Worker управляет доступом и `chrome.storage.local`. Нет телеметрии, рекламы, записи аудиофайлов, синхронизации пресетов или отправки аудио на сервер. Runtime JavaScript включён в пакет; удалённый код не загружается.

Разрешения: `activeTab`, `tabCapture`, `offscreen`, `storage`. Нет host permissions, content scripts и разрешения истории посещений. Во время работы в памяти находятся ID и название подключённой вкладки для списка Active Tabs.

Захват служебных страниц и некоторых DRM-плееров может быть запрещён браузером. Большие усиления могут перегружать звук — дополнительного скрытого лимитера нет. Подробнее: [Privacy policy](PRIVACY_POLICY.md), [архитектура](docs/ARCHITECTURE.md), [аудит безопасности](docs/SECURITY_AUDIT.md).

## Проверки и разработка

Node.js 20+; `npm test` запускает статические и unit-проверки без установки дополнительных пакетов. Для браузерных тестов: `npm ci`, затем `npm run test:chrome` или `npm run test:yandex`. Путь браузера можно указать через `EARS_BROWSER`. Тесты используют отдельные профили и беззвучный Web Audio sink до воспроизведения тестовых тонов.

Упаковка: `python tools/build.py` (Python 3.10+). ZIP установки и архив исходников появятся рядом с проектом. GitHub Actions проверяет код и упаковку; полноценные аудиотесты запускаются отдельно. Он не публикует магазинные релизы автоматически.
