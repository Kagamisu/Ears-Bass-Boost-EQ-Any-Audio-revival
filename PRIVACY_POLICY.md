# Privacy policy — Ears 1.3.12 Revival

Effective date: 27 October 2026. Applies to the build 1.3.14.

Ears Revival processes audio from tabs that you connect by opening the extension. Audio is processed locally in your browser using Web Audio. The extension does not upload audio, record audio files, use analytics, display advertisements, sell data, or contact an external server.

While capture is active, the extension keeps the tab ID and tab title in memory to display the Active Tabs list. It does not store these values as browsing history. The extension does not request access to browsing history and does not inject scripts into websites.

Equalizer parameters, output gain and presets are stored locally using the browser's extension storage. The selected interface panel and spectrum preference are stored in the extension's local UI storage. They are not synchronized through chrome.storage.sync. You can export presets to a JSON file; that file contains the preset names and filter parameters you chose. Keep exported files private if their names contain information you do not want to share.

You can stop capture for any tab through Ears or the browser's capture controls. Closing the browser ends all streams. The extension does not automatically restart capture after a browser restart. Deleting a preset removes it from extension storage; uninstalling the extension removes the browser-managed extension data. Exported files and files you manually backed up must be removed separately.

External links in the Guide open only when you click them. The destination website's privacy policy then applies. The browser itself and the websites you visit may make their own network requests; those are outside this extension's processing.
