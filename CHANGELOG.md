# 1.3.15 — пакет для Opera Add-ons

Snap.svg обновлена до неизменённой upstream 0.5.1. Убран неиспользуемый earss.svg. Дизайн, аудиофильтры и разрешения не менялись. Проверки Chrome и Яндекса прошли; проверка в самой Opera пока не проводилась.

# Что менялось

## 1.3.14 · 27 октября 2026

Версия для GitHub. Чуть изменились два цвета: фон стал `#293B4B`, основной цвет — `#F0D6A5`. Точки, шкалы, расположение кнопок и обработка звука остались прежними.

Добавились инструкция установки, контакты, скриншоты и GitHub Actions. Проверка на GitHub запускает тесты и собирает ZIP, но ничего сама не отправляет в магазин.

## 1.3.13 · 27 октября 2026

Перенос старой Ears на Manifest V3. Постоянную фоновую страницу заменили worker и offscreen-документ: один управляет расширением, второй держит аудио. Поэтому закрытие popup и остановка worker не обрывают обработку.

Из заметного:

- Остались те же 11 фильтров, границы настройки, шкала громкости и Bass Boost на 340 Гц / +5 дБ. CSS этой версии был сохранён побайтно.
- Сохранились общий EQ для подключённых вкладок, их отдельное отключение и старый формат пресетов.
- Фильтры теперь соединены постоянно, а изменения сглаживаются за несколько миллисекунд. Это убрало перестройку соединений при каждом движении точки.
- Кривые на графике считаются через `getFrequencyResponse`. Визуализатор больше не копит SVG-градиенты, а ненужный analyser отключается примерно через 1,1 секунды.
- При остановке вкладки освобождаются все её tracks и source node. После последней вкладки закрываются AudioContext и offscreen.
- Настройки и пресеты перенесены в локальное хранилище. Импорт проверяет формат и числа; экспорт освобождает созданный Blob URL.
- Убраны Google Analytics, удалённый JS, storage.sync, рекламные и неработающие Pro-ссылки. Из Snap.svg убран неиспользуемый AJAX-транспорт.
- Оставлены четыре разрешения: activeTab, tabCapture, offscreen, storage. Старые key, update_url и _metadata в сборку не попали.
- Исправлена ссылка Full Window для нового ID. Добавлены тесты, сборка и заметки по устройству расширения.
