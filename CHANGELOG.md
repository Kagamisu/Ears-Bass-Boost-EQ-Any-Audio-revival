# Изменения

## 1.3.14 — GitHub edition, 27 октября 2026

- Добавлен публичный репозиторий проекта с установкой через Load unpacked и GitHub Actions для статических тестов и проверки упаковки.
- Сохранены исходная компоновка и аудиофункции 1.3.13. Только фон #2C3E50 заменён на #293B4B и wheat — на #F0D6A5; акцентные точки и размеры графика не изменены.
- Сохранены атрибуция Kevin King, смешанные условия лицензирования и предупреждение, что проект не является официальным релизом оригинального автора.
- Публичный исходный код не является подтверждением прав на все унаследованные материалы или одобрения Chrome Web Store.


## 1.3.13 — Ears 1.3.12 Revival, 27 октября 2026

- Manifest V2 заменён реальной архитектурой MV3: service worker управляет доступом к вкладкам и хранилищем, offscreen-документ держит Web Audio и MediaStream.
- `browser_action` заменён `action`; `tabCapture.capture()` и `tabs.getSelected()` заменены `getMediaStreamId()`, `getUserMedia()` и `tabs.query()`.
- Сохранены 11 фильтров, их типы и порядок, default Q 0.7071, исходные границы регулировки и единственный встроенный Bass Boost.
- CSS оригинала сохранён побайтно. Оригинальные SVG-регуляторы, Snap.svg, шкалы, вкладки, пресеты и управление перетаскиванием адаптированы, а не переписаны.
- Сохранены общий EQ и независимое подключение нескольких вкладок; закрытие popup и остановка worker не прерывают обработку.
- Все 11 фильтров постоянно соединены последовательно; фильтры с gain 0 прозрачны. Убрана перестройка соединений на каждом движении точки. Регулировки сглаживаются с постоянной времени 8 мс.
- Кривые частотной коррекции рассчитываются нативным `getFrequencyResponse`, вместо неточного приближённого расчёта оригинального popup. Внешний вид графика сохранён.
- Устранено накопление SVG-градиентов. FFT 8192 и smoothing 0.5 сохранены; ненужный analyser освобождается через ~1,1 с.
- Остановка вкладки освобождает все её tracks и source node; последний поток закрывает AudioContext и offscreen-документ. Внешняя остановка и закрытие вкладки обрабатываются.
- При открытии интерфейса живой контекст получает актуальные сохранённые параметры и попытку возобновления.
- Удалены Google Analytics, удалённая загрузка JS, storage.sync, рекламная ссылка, неработающие Pro/purchase-сообщения, оригинальные `key`, `update_url`, `_metadata`.
- Требуются только activeTab, tabCapture, offscreen, storage. Удалено разрешение tabs; host permissions и content scripts отсутствуют.
- Snap.svg 0.4.1 сохранён с удалением неиспользуемого сетевого транспорта Snap.ajax. Лицензия, upstream NOTICE и отметка изменения приложены.
- Пресеты сохраняются только локально. Добавлены проверка формата JSON, конечности чисел, границ параметров, размера файла и защита специальных имён объектов.
- Экспорт JSON выполняется в popup через Blob URL с освобождением URL; дополнительных разрешений не нужно.
- Исправлена ссылка Full Window под новый ID; коммерческий footer заменён атрибуцией оригинального автора.
- Подготовлены воспроизводимая упаковка, статические и реальные браузерные тесты, документы по архитектуре, безопасности, privacy и правам публикации.
