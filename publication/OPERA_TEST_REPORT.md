# Проверка пакета Opera 1.3.15

27 октября 2026: npm test — 8/8. Реальные Chrome 156.0.8078.48 и
Яндекс 26.10.0.1854 прошли браузерный сценарий с настоящим захватом
HTML5-аудио. Проверены Bass Boost (около +4.9 dB), график, перетаскивание
точек, Shift/Q, общий gain, пресеты, импорт/экспорт, две вкладки,
закрытие панели, остановка service worker, 8 переподключений и восстановление
настроек после перезапуска тестового профиля. Отклонение АЧХ от оригинала:
0 dB в 3 конфигурациях по 256 частот. Фоновая выдержка — 5 секунд;
это не тест многочасовой работы. HTTP-запросов расширения и JS-ошибок не было.

Сигнал выводился в беззвучный Web Audio sink, без звука в наушниках.
Snap.svg 0.5.1 проверена по SHA-256; файл из официального тега не изменён.
Собственный код не использует её AJAX/загрузку внешних SVG;
сетевые соединения расширения запрещены CSP connect-src none.

В Opera, macOS и Linux эта сборка ещё не проверена. Приём пакета сайтом
и отправка на модерацию не означают успешную проверку совместимости Opera.
Поведение на YouTube/защищённых потоках и многочасовая нагрузка в этой
сессии отдельно не проверялись. Подробные результаты и снимки — docs/test-evidence/.
