# Opera Add-ons: сборка 1.3.15

Основа — опубликованная GitHub-версия 1.3.14. Интерфейс и аудиологика те же.
Для требований Opera взята неизменённая Snap.svg 0.5.1 из официального тега v0.5.1.
Неиспользуемый earss.svg убран. Разрешения и CSP не расширялись.
Готовый пакет содержит runtime и обязательные уведомления о лицензиях.

Описание для карточки:

Ears Revival — неофициальное восстановление привычного Ears для Manifest V3.
Открой вкладку с музыкой, нажми значок расширения и двигай точки на графике.
Есть 11 фильтров, Bass Boost, общая громкость, визуализатор и свои пресеты
с импортом и экспортом. Shift + перетаскивание меняет ширину фильтра,
двойной клик сбрасывает одну точку.

Звук продолжает обрабатываться после закрытия панели. Можно подключить
несколько вкладок; настройки эквалайзера у них общие, а отключаются они
по отдельности. После перезапуска браузера настройки сохраняются,
но вкладки нужно подключить заново.

Всё аудио обрабатывается внутри браузера. Нет рекламы, аналитики,
записи аудио и отправки звука на сервер. Настройки хранятся локально.
