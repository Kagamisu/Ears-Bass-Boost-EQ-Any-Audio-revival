# Что осталось до магазина

На GitHub лежат исходники для ручной установки. Публикации в Chrome Web Store пока нет.

До отправки туда нужно разобраться с правами на унаследованные материалы, заполнить карточку, проверить privacy policy и поддержку, пройти ручной сценарий из [отчёта](../docs/TEST_REPORT.md). Авторство и условия для разных частей описаны в [LICENSE.md](../LICENSE.md).

Обычный `python tools/build.py` собирает локальный ZIP. Вариант `--public` дополнительно проверяет `rights-clearance.json` и `release.json`. Публикация исходников и смена цветов сами эти статусы не меняют.

Назначение расширения для карточки магазина: локальный эквалайзер звука вкладок. activeTab выбирает вкладку по действию пользователя; tabCapture получает аудио; offscreen держит обработку; storage сохраняет настройки. Аудио и заголовки подключённых вкладок используются локально — это нужно так и описать.
