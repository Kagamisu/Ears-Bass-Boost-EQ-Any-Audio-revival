# Отдельный выпуск в магазин

Исходники размещаются в GitHub по запросу сопровождающего. Это не подтверждение прав на все унаследованные материалы и не одобрение Chrome Web Store. Смешанные условия и атрибуция сохранены в LICENSE.md.

Путь `python tools/build.py` собирает ZIP для локальной установки. Путь `--public` предназначен для отдельной подготовки магазинного пакета и проверяет `rights-clearance.json` и `release.json`. Статусы прав не меняются автоматически из-за публикации исходников или смены палитры.

Перед магазином нужно проверить происхождение компонентов, metadata, privacy policy и поддержку, выполнить ручные браузерные сценарии из `docs/TEST_REPORT.md`. В metadata нельзя заявлять официальное продолжение/одобрение оригинального автора без основания.

Single purpose: local tab-audio equalization. activeTab выбирает вкладку действием пользователя; tabCapture получает её аудио; offscreen сохраняет Web Audio после закрытия popup; storage хранит локальные параметры. Звук и временные названия вкладок обрабатываются локально. Не утверждайте, что расширение вообще не обращается к аудио или заголовкам вкладок.
